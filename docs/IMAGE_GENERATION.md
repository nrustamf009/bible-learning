# Как сделать настоящие картинки

В `art/` лежат **готовые векторные иллюстрации**, нарисованные кодом (`tools/render_art.py` + `tools/art_engine.py`): 12 панелей пилота в двух стилях, 16 обложек эпизодов 1–8 и листы героев. Их можно публиковать как есть. Если захочется более живописный финал, генератор или иллюстратор делает картинки по промптам, а векторные рисунки служат им композиционным эталоном: та же сцена, те же герои, те же места для реплик.

## Главное правило: сначала герои, потом сцены

Генераторы рисуют каждый раз немного другое лицо. Чтобы Пётр в 40-м эпизоде был тем же Петром, что и в 1-м:

1. Сгенерировать **лист героя** (4 ракурса + 3 эмоции) для каждого героя в каждом стиле — промпты в `prompts/characters/<style>/<hero>.txt`. Сделать 3–4 варианта, выбрать лучший, сохранить как `art/<style>/characters/<hero>.png`.
2. Для каждой панели **прикладывать листы героев**, которые в ней есть, как референсы + промпт панели из `prompts/<episode>/<style>/<panel>.txt`.
3. Размер **1536×1024** (3:2). Текста в картинке быть не должно.
4. Сохранить как `art/<style>/<episode>/<panel>.png`; для панелей с Христом — ещё вариант с нимбом `<panel>.orthodox.png` (промпт `<panel>.orthodox.txt`).
5. `python3 tools/build_reader.py` — читалка сама подставит картинки вместо эскизов.
6. Открыть читалку и подвинуть хвостики пузырей (`tx`, `ty` в `episode.json`), если герой оказался в другом месте.

## Вариант A: Codex / ChatGPT (без программирования)

Готовая задача для Codex (вставь как есть):

```text
Открой репозиторий nrustamf009/the-last-mile, ветку claude/mark-gospel-comics-f5fhgt, папку mark-gospel-comics.
1. Прочитай docs/IMAGE_GENERATION.md и docs/STYLE_GUIDE.md.
2. Для каждого файла в prompts/characters/kids/ сгенерируй картинку 1536x1024 по этому промпту
   и сохрани в art/kids/characters/<имя>.png. То же для prompts/characters/adults/.
3. Затем для каждого файла prompts/ep12-storm/<style>/<panel>.txt сгенерируй картинку 1536x1024,
   приложив как референсы листы героев из art/<style>/characters/ для героев этой панели
   (список героев — в episodes/ep12-storm/episode.json, поле characters).
   Сохрани в art/<style>/ep12-storm/<panel>.png (для *.orthodox.txt — <panel>.orthodox.png).
4. Запусти python3 tools/build_reader.py и закоммить результат.
Важно: в картинках не должно быть текста и пузырей.
```

В обычном ChatGPT: открой вкладку «Промпты для картинок» в читалке, нажми «Копировать», вставь в чат, приложи листы героев.

## Вариант B: скрипт через OpenAI API

```bash
pip install openai
export OPENAI_API_KEY=...            # ключ не коммитить
python3 tools/build_prompts.py
python3 tools/generate_images.py prompts/characters/jobs.json --dry-run   # посмотреть план
python3 tools/generate_images.py prompts/characters/jobs.json             # листы героев
python3 tools/generate_images.py prompts/ep12-storm/jobs.json             # панели (с референсами)
python3 tools/build_reader.py
```

Модель меняется флагом `--model`. Примерно 24 листа героев + 18 панелей на эпизод.

## Вариант C: другие генераторы

- **Midjourney**: вставлять промпт, лист героя прикладывать как `--cref` (character reference), стиль — `--sref` с первой удачной панели.
- **Flux / Stable Diffusion**: обучить LoRA на каждого главного героя по его листу — самое стабильное постоянство лиц на 40 эпизодов.
- **Иллюстратор**: отдать ему `docs/STYLE_GUIDE.md`, листы героев, раскадровку (`episode.json` → поле `scene`) и эскизы из `art/` как композиционные наброски.

## Лицензии

Проект некоммерческий. Проверь условия выбранного генератора: у большинства сгенерированные картинки можно публиковать, но условия меняются. Шрифты в читалке — Google Fonts (свободная лицензия OFL).
