# Чек-лист проверки эпизода

Каждый эпизод перед публикацией проходит три проверки. Отмечать в `data/episodes.json` → `status`: `draft` → `review` → `published`.

## 1. Текст Писания
- [ ] Текст отрывка совпадает с печатным изданием (Синодальный / BSB), включая знаки.
- [ ] Реплики в комиксе передают слова Марка; у детей упрощено без нового смысла.
- [ ] Нет придуманных слов Иисуса или учеников.
- [ ] Ссылки на стихи и параллели верные; нумерация псалмов по нужной традиции.

## 2. Богословие (отдельно для каждой традиции)
- [ ] **Православная версия** прочитана священником; формулировки соответствуют учению Православной Церкви.
- [ ] **Протестантская версия** прочитана пастором; формулировки приемлемы для основных евангельских церквей.
- [ ] Общие части (комикс, «Что произошло», «Фон») не содержат спорного для одной из традиций.
- [ ] Каждая мысль учителей сверена с источником; `verify` снят.
- [ ] Главная мысль одна и выводится из текста.

## 3. Для читателя
- [ ] Дети: прочитано вслух ребёнку 6–8 лет; понятно без объяснений взрослого.
- [ ] Шаги «Применить» конкретны: что сделать, когда, сколько.
- [ ] Вопросы открытые (не «да/нет»).
- [ ] Картинки: герои узнаваемы по стиль-гайду; нет текста в картинке; нет пугающих деталей у детей.
- [ ] Пузыри не закрывают лица; хвостики указывают на говорящих.
- [ ] Носитель языка проверил каждый язык.
