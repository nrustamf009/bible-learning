# Марк на полях · Mark in the Margins

Комиксы по Евангелию от Марка для нового поколения: после каждого эпизода идут простое объяснение, мысли проповедников и учителей Церкви, главная мысль и практические шаги «как применить на этой неделе».

| | |
|---|---|
| Традиции | **православная** и **протестантская** — отдельные толкования, доктрина и практика; картинки общие (в православной версии у Христа добавляется нимб) |
| Языки | **русский**, **английский** (структура готова к любым другим) |
| Читатели | **дети 6–11** (яркий мультяшный стиль) · **подростки и взрослые** (современный графический роман) |
| Готово | Сезон 1 (эпизоды 1–8) и эпизод 12 «Буря на озере»: 54 панели в двух стилях, у каждой — пояснение на полях в трёх голосах; словарь из 26 слов |
| Проект | некоммерческий |

## Три дизайна

Переключатель «Дизайн» в шапке читалки:

| Дизайн | Идея |
|---|---|
| **Книга** | глосса: лента комикса и пояснения на полях, шрифт Old Standard, лазурь на бумаге |
| **Икона** | тёмная доска, золото, киноварь, заголовки шрифтом в духе вязи (Ruslan Display), панели в рамах-клеймах, буквицы |
| **Комикс** | журнал комиксов: белая бумага с растром, толстые контуры, жёсткие тени, CMYK-цвета, пояснения как реплики |

## Как посмотреть

Открой `site/index.html` в браузере. При первом запуске читалка спрашивает, кто читает (дети/взрослые), традицию и язык; от выбора меняется даже внешний вид. Есть библиотека с сезонами, режим чтения «по кадрам» (реплики появляются по одной, стрелки ←/→), игра для запоминания стиха, отметки шагов «на этой неделе», вкладки «Герои» и «Студия» (промпты для генераторов).

## Что где лежит

```
mark-gospel-comics/
  data/
    scripture/en-bsb/mark.json      весь Марк, Berean Bible (public domain)
    scripture/ru-synodal/mark.json  Синодальный (пока только отрывки пилота — сверить!)
    characters.json                 библия персонажей + два стиля + слой нимба
    sources.json                    комментаторы (только public domain), по традициям
    episodes.json                   карта серии: 6 сезонов, 41 эпизод
  episodes/ep12-storm/
    episode.json                    раскадровка: панели, сцены для 2 стилей, реплики, позиции пузырей
    content.json                    тексты после комикса: традиция × возраст × язык
  art/<kids|adults>/                иллюстрации (SVG): ep12-storm/, covers/, character-sheet.svg; сюда же можно класть PNG
  prompts/                          готовые промпты (генерируются из data/)
  site/                             веб-читалка
  tools/                            скрипты (см. ниже)
  docs/                             архитектура, стиль, источники, генерация картинок, проверка
```

## Скрипты

Всё сразу: `./tools/build_all.sh`.

Кадры сезона 1 описаны один раз в `tools/authoring/season1_scenes.py` (место, время, герои, позы, предметы) и рисуются в обоих стилях модулем `tools/scenes.py`.


| Команда | Что делает |
|---|---|
| `python3 tools/build_prompts.py` | собирает промпты для всех панелей и листов героев → `prompts/` |
| `python3 tools/generate_images.py prompts/characters/jobs.json` | генерирует листы героев через OpenAI Images API |
| `python3 tools/generate_images.py prompts/ep12-storm/jobs.json` | генерирует панели с листами героев как референсами |
| `python3 tools/render_art.py` | рисует все иллюстрации: 12 панелей пилота, 16 обложек, листы героев, заглавные картинки (детский стиль — `tools/art_engine.py`, взрослый — `tools/silhouette.py` + `tools/render_adults.py`) |
| `python3 tools/authoring/glosses.py` | пишет словарь (data/glossary.json) и пояснения на полях к пилоту |
| `python3 tools/authoring/season1.py` | пересобирает эпизоды 1–8 из исходника (тексты, раскадровки) |
| `python3 tools/fetch_scripture.py` | скачивает полный текст Марка (BSB + Синодальный) с ebible.org |
| `python3 tools/build_reader.py` | собирает читалку `site/index.html` |
